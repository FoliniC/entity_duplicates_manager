# Piano: Statistica Utilizzo Internet Periodica

## Obiettivo
Aggiungere nella dashboard `/internet-traffic/traffico-internet` una card che mostra il consumo totale in MB dell'internet da una certa data (default: 23 del mese), con suddivisione per fonte/dispositivo.

## Analisi del Sistema Esistente
- Il router OpenWrt ha `nlbwmon` che traccia traffico totale per dispositivo (byte cumulativi)
- `sensor.router_traffic_stats` fornisce `total_rx_mb` e `top_consumers` ogni 60s
- `sensor.router_total_download` ha `state_class: total_increasing` (MB)
- Esiste InfluxDB per statistiche storiche
- Il pattern `utility_meter` è già usato per le statistiche energetiche

## Implementazione

### 1. Nuovo Helper Python (`helpers/monthly_traffic_stats.py`)
Script che:
- Si collega al router via SSH e legge i dati nlbwmon
- Gestisce uno snapshot mensile salvato in `/config/temp/monthly_traffic_snapshot.json`
- Al primo avvio di ogni mese (o quando si supera il giorno di inizio), salva i valori correnti come "punto di partenza"
- Calcola e restituisce la differenza totale e per dispositivo

### 2. Sensori Template (in `packages/network_monitoring.yaml`)
- `sensor.internet_usage_period_total` - MB totali consumati dal periodo
- `sensor.internet_usage_period_by_device` - attributi con consumo per dispositivo

### 3. Input Helpers (in `yaml_generator/input_number/`)
- `input_number.internet_usage_start_day` - Giorno di inizio periodo (default: 23, range: 1-31)

### 4. Card Dashboard (`dashboards/internet_traffic.yaml`)
Aggiungere nella dashboard "Traffico internet" (colonna sinistra, dopo "Riepilogo Storico"):
- Titolo: "📊 Utilizzo Periodico (MB)"
- Input per impostare il giorno di inizio
- Tabella con:
  - Totale MB consumati dal periodo
  - Top 5 dispositivi per consumo nel periodo
  - Data iniziale periodo

## Pattern di Codice

L'helper segue lo stesso pattern di `router_traffic.py`:
- Cache file in `/config/temp/`
- SSH con chiave dedicata
- Output JSON con `period_total_mb` e `period_by_device` array

I sensori template seguono lo stesso pattern del resto del file `network_monitoring.yaml`.

## Dettagli Tecnici

```python
# monthly_traffic_stats.py
- Controlla se file snapshot esiste
- Se non esiste o se abbiamo superato il giorno di reset: salva snapshot corrente
- Legge traffico corrente
- Calcola differenze (MB) totale e per dispositivo
- Output: {"period_total_mb": X, "period_by_device": [{"name": "Device", "period_rx_mb": Y}]}
```
